# FastWAM Memory Full-KV Baseline

This tree starts from the official FastWAM commit
`45d8e1458921d83f8ad6cf9ce993d371208dabd0`.

The first baseline keeps the official 5B VideoDiT and independent 1B
ActionDiT. At each decision point it builds:

1. all strictly earlier clean observation latents;
2. the current clean observation latent;
3. the current noisy future-video latent;
4. the current noisy 16-step action chunk.

The training mask is causal over clean observations. Noisy future video reads
all clean observations and its diffusion group. Action reads all clean
observations and action tokens, but never noisy future video.

At inference, each clean observation is forwarded through VideoDiT once.
Every layer appends its K/V to an unbounded cache, and ActionDiT reads all
retained video K/V at every denoising step. No frame compression, gist token,
sliding window, or eviction is used in this baseline.

Initialization is generated by the official
`scripts/preprocess_action_dit_backbone.py`: VideoDiT comes from
Wan2.2-TI2V-5B, while the 1B ActionDiT backbone is linearly interpolated from
the VideoDiT with the official alpha scaling. The action input/output heads
and 14D proprio projection retain their normal FastWAM initialization.
